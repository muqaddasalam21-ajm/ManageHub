| **Scope Creep** | Management | Unplanned features (e.g., social auth, payments) could disrupt timeline. | **Controlled Risk** | Enforce strict Out-of-Scope boundaries defined in Section 10 of Project Charter. |
| **Authentication Security** | Technical | Improper JWT storage or unverified tokens could compromise user sessions. | **Mitigated in Plan** | Rely on Supabase Auth and stateless JWT middleware verification on all private routes. |
| **Database Configuration** | Technical | Remote PostgreSQL connection pool timeouts or connection string errors. | **Mitigated in Plan** | Standardize `.env.example` templates; test connection strings during Week 2 framework design. |
| **API Integration Discrepancies** | Technical | Frontend fetch models not matching backend controller JSON response envelopes. | **Mitigated in Plan** | Establish shared TypeScript interfaces for all payloads during Week 2 contract design. |
| **Testing Delays** | Quality | Postponing automated testing could hide regressions until final week. | **Mitigated in Plan** | Author automated tests concurrently with API controllers during Week 3 execution. |
| **Deployment Issues** | Operations | CORS configuration failures or build-time environment variable omissions. | **Mitigated in Plan** | Configure dynamic CORS middleware; perform dry-run production builds early in Week 4. |
